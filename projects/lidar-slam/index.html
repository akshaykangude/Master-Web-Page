Full 2D LiDAR SLAM simulator — raycasting, occupancy-grid mapping, A* navigation with live obstacle avoidance, proximity safety zones, scan recording, and map save/load — running entirely in your browser via Pyodide. Same Python simulation engine as the desktop pygame app.

Controls
Navigate tool: Arrow keys / WASD to move, Q/E to rotate.
Circle / Box: click scene to place.
Wall: click+drag to draw, right-click to cancel.
Move / Resize: click object, then drag.
Delete: click object or wall.
Go To: click destination — robot path-plans & follows automatically.
Room Size: drag orange corner handles.
Record → drive around → Save Map downloads a .json file. Load Map restores it (including for Calibrate's pose matching).
